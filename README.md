# Departamento de Vendas

Projeto de análise e previsão de vendas utilizando o conjunto de dados **Rossmann Store Sales**.

## Sobre o projeto

O projeto explora dados históricos de vendas de lojas da Rossmann, identificando padrões relacionados a clientes, promoções, dias da semana e características das lojas.

Também é utilizado o modelo **Prophet** para realizar previsões de vendas de uma loja específica para os próximos 60 dias.

## Principais etapas

- Análise exploratória dos dados;
- Tratamento de valores ausentes;
- Integração dos dados de vendas e lojas;
- Criação de variáveis temporais;
- Análise de vendas, clientes e promoções;
- Previsão de vendas com Prophet;
- Exportação das previsões para um arquivo CSV.

## Tecnologias utilizadas

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Facebook Prophet

## Arquivo principal

- `departamento-de-venda.ipynb`: notebook com toda a análise e o modelo de previsão.
